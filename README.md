Application Requirements
1. Equipment inventory: Create, view, update, delete and search equipment
records, including equipment identifiers, descriptions, locations and
availability.
2. Equipment booking: Allow authorised users to book equipment, manage
bookings and prevent conflicting reservations.
3. Fault reporting: Allow users to report equipment faults and record relevant
information about the issue.
4. Maintenance management: Schedule maintenance activities, assign
technicians and identify overdue maintenance.
5. Equipment status: Manage equipment status transitions, such as available,
booked, under maintenance and out of service.
6. User roles: Support appropriate access permissions for different user types.
7. Reporting: Provide relevant summaries, such as equipment availability,
outstanding faults and maintenance activity.
8. Data management: Provide data persistence, validation and appropriate
error handling
